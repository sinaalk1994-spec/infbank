# صنف‌یار — تصمیم‌های طراحی

- محصول یک پنل فارسی مدیریت پرونده‌ها، حق عضویت، دریافت‌ها و دسترسی کاربران است.
- رابط با Django templates، JavaScript ساده و CSS ثابت ساخته می‌شود؛ افزودن React، Tailwind یا مرحله build در دامنه‌ی این پروژه نیست.
- جهت صفحه RTL و فونت اصلی Vazirmatn است.
- زبان بصری از سرمه‌ای شبانه و بنفش با تأکیدهای آبی و طلایی ملایم استفاده می‌کند. نقش هندسی فارسی موجود در `static/images/geometric-motif.svg` فقط برای عمق بصری و به‌صورت محدود استفاده می‌شود.
- داده‌های مالی باید از جلوه‌های تزئینی مهم‌تر و خواناتر بمانند: جدول‌های فشرده اما روشن، ارقام واضح، وضعیت‌های معنایی و فرم‌های بخش‌بندی‌شده.
- دسترس‌پذیری صفحه‌کلید، فوکوس واضح، نمایش موبایل و کاهش حرکت حفظ می‌شود.
- تغییر یا حذف تعرفه و برگشت مالی باید تأیید مدیر و دلیل ثبت‌شده داشته باشد؛ بدهی‌های صادرشده بدون اقدام صریح تغییر نمی‌کنند.
