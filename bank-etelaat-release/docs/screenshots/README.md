# پیش‌نمایش صنف‌یار

این تصاویر از نسخه اجراشده سامانه گرفته شده‌اند. نام‌ها، پرونده‌ها و مبالغ همگی **ساختگی و مخصوص نمایش** هستند.

> تصاویر مربوط به رابط فعلی‌اند. امکان بارگذاری دو لوگو و تنظیم سربرگ متنی در این نسخه وجود دارد؛ درخواست جدید بارگذاری سربرگ کامل PNG با جای قابل‌تنظیم تاریخ، شماره و پیوست هنوز در این تصاویر اعمال نشده است.
